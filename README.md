# سَكَن (SAKAN) — منصة السكن المباشر الأولى في مصر

> **"سكنك أقرب. وحقك محفوظ."**  
> المنصة الرقمية المباشرة لربط طلبة الجامعات والموظفين المغتربين في مصر بأصحاب الشقق والغرف مباشرة وبدون عمولات سماسرة.

---

## 1. الرؤية والمبادئ الأساسية (Product Vision)

1. **بدون عمولات سماسرة (Zero Brokerage Commissions):** المنصة مجانية ١٠٠٪ ولا تتقاضى أي نسبة من الإيجار.
2. **تواصل مباشر وآمن:** محادثات فورية مشفرة وخاصة بين الطرفين داخل المنصة.
3. **شفافية كاملة في الأسعار والمواصفات:** بالجنيه المصري (EGP)، وتحديد الفواتير والتأمين بوضوح.
4. **حماية الخصوصية (Privacy-First):** إخفاء أرقام الهواتف والعناوين الدقيقة افتراضياً، وعدم جمع بطاقة الرقم القومي افتراضياً.
5. **خدمة "دوّرلي على سكن":** محرك مطابقة ذكي ينبه الباحثين فور نشر إعلان سكن يطابق ميزانيتهم ومواصفاتهم المطلوبة.
6. **رقابة عادلة ومكافحة الاحتيال:** لوحة إشراف إدارية متكاملة للتعامل مع بلاغات السماسرة والإعلانات المخالفة.

---

## 2. البنية التقنية (Tech Stack)

- **Frontend:** Next.js 16 (App Router), React 19, TypeScript (Strict Mode).
- **Styling & RTL:** Tailwind CSS v4, تصميم عربي أصيل موجه لليمين (RTL).
- **Icons & UI:** Lucide Icons, مكونات مصممة بأعلى معايير الوصول والتباين وسهولة الاستخدام.
- **Backend & Database:** Supabase PostgreSQL مع تفعيل سياسات الأمان على مستوى الصف (RLS) بنسبة 100%.
- **Authentication:** Supabase Auth مع تطبيع والتحقق من أرقام الهواتف المصرية (+20 / 01x).
- **Storage:** Supabase Storage (4 حاويات مع سياسات وصول دقيقة).
- **Testing:** Vitest لاختبارات الوحدات ومحرك المطابقة وسياسات الأمان.

## 4. التشغيل والتطوير المحلي (Quick Start)

### المتطلبات الأساسية
- Node.js 18+ (أو الإصدار الحالي v24)
- npm 9+

### خطوات التشغيل:
```bash
# 1. الدخول إلى مجلد المشروع
cd sakan

# 2. نسخ المتغيرات البيئية
cp .env.example .env.local

# 3. تثبيت الحزم والمكتبات
npm install

# 4. تشغيل الاختبارات الآلية للتحقق
npm run test

# 5. بناء حزمة الإنتاج
npm run build

# 6. تشغيل الخادم
npm run start
# أو في وضع التطوير:
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

## 5. تهيئة Supabase للإنتاج (Production Setup)

1. أنشئ مشروعاً جديداً على [Supabase](https://supabase.com).
2. افتح **SQL Editor** ونفّذ ملفات الترحيل بالترتيب:
   - `supabase/migrations/001_initial_schema.sql`
   - `supabase/migrations/002_row_level_security.sql`
   - `supabase/migrations/003_storage_policies.sql`
3. انسخ بيانات المشروع من لوحة التحكم (Settings -> API):
   - `Project URL` وضعها في `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public key` وضعها في `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `service_role secret key` وضعها في `SUPABASE_SERVICE_ROLE_KEY`
4. لتعيين أول مدير نظام فائق (Super Admin)، سجّل حسابك عبر `/signup` ثم نفّذ الاستعلام التالي في Supabase SQL Editor:
   ```sql
   insert into public.user_roles (user_id, role)
   values ('<USER_UUID>', 'super_admin');
   ```
